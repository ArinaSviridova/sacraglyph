# Image speed v17

Что сделано:

- Для фото из Supabase Storage сайт теперь использует Supabase Image Transform вместо полного оригинала.
- Превью работ и мерча получают уменьшенные версии по ширине, а не тяжелый исходник.
- Лайтбокс открывает более крупную, но всё равно оптимизированную версию.
- Добавлены `preconnect` и `dns-prefetch` к Supabase, чтобы браузер раньше открывал соединение.
- Первые видимые фото получают `loading="eager"` и `fetchpriority="high"`.
- Остальные фото лениво догружаются и прогреваются пачками после загрузки страницы, чтобы не душить первый экран.
- Новые фото в админке сжимаются сильнее: max side 1600px, quality 0.78.
- Добавлен `_headers` для долгого кэша статических assets на Netlify.

Важно: абсолютной мгновенности для всех фото не существует. Если загрузить сразу вообще все оригиналы, сайт станет медленнее на первом экране. Поэтому сделана нормальная схема: быстрые превью + прогрев остальных фото после рендера.
