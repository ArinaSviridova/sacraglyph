Политика конфиденциальности

Дата последнего обновления: 10.03.2026

Эта политика конфиденциальности объясняет, какие данные может собирать сайт bazookatattoo, для чего они используются и как с ними обращаются. Если ты оставляешь заявку через сайт, ты подтверждаешь, что ознакомился(-ась) с этой политикой.

1. Кто обрабатывает данные

Сайт используется для связи с тату-мастером Nikita Presnyakov / bazookatattoo. По вопросам, связанным с обработкой данных, можно связаться через контакты, указанные на сайте.

2. Какие данные могут собираться

При использовании сайта могут собираться следующие данные:

  • имя, указанное в форме обратной связи;
  • способ связи, который ты укажешь сам(-а) в форме;
  • номер телефона и email, если ты укажешь их дополнительно;
  • технические данные, связанные с отправкой формы и использованием сайта;
  • данные о действиях на сайте, если используются инструменты аналитики и рекламного отслеживания.

3. Для чего используются данные

  • для ответа на заявку и связи с тобой;
  • для обсуждения записи, консультации и деталей тату-проекта;
  • для улучшения работы сайта;
  • для анализа эффективности рекламы и источников обращений.

4. Как отправляются данные из формы

Данные, отправленные через форму на сайте, могут передаваться через сторонние технические сервисы, которые используются для работы сайта и получения заявок. Например, данные могут быть переданы в хостинг/серверные инструменты сайта и в Telegram-бота, который используется для получения уведомлений о новых заявках.

5. Аналитика и рекламные инструменты

На сайте могут использоваться инструменты аналитики и рекламного отслеживания, включая Google Ads и связанные теги Google, для оценки эффективности рекламы, фиксации конверсий и улучшения рекламных кампаний.

Если включены соответствующие функции Google, сайт может использовать данные, предоставленные пользователями, в объёме, необходимом для отслеживания рекламных конверсий и повышения точности аналитики.

6. Передача данных третьим лицам

Данные не продаются и не передаются посторонним лицам. При этом отдельные данные могут обрабатываться сторонними сервисами, которые обеспечивают работу сайта, формы обратной связи, рекламной аналитики и доставки уведомлений.

7. Срок хранения данных

Данные хранятся столько, сколько это необходимо для ответа на обращение, ведения переписки, записи на сеанс, а также для технических и аналитических задач сайта. По запросу данные могут быть удалены, если их дальнейшее хранение не требуется.

8. Права пользователя

Ты можешь запросить уточнение, изменение или удаление своих данных. Для этого достаточно написать по одному из контактов, указанных на сайте, и указать, какие именно данные нужно удалить или исправить.

9. Безопасность

Принимаются разумные технические меры для защиты данных, однако ни один способ передачи данных через интернет не может считаться абсолютно защищённым. Да, цифровой мир всё ещё держится на скотче и надежде.

10. Изменения политики

Эта политика может обновляться. Актуальная версия всегда публикуется на этой странице.
